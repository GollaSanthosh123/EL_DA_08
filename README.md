# Superstore Sales Analysis – Power BI Project

This project showcases a data analysis and visualization task using **Power BI Desktop** on a retail dataset called `Superstore_Sales.csv`.

## Files Included

- `Superstore_Sales.csv` – The dataset used for analysis
- `Superstore_Sales_Insights.pptx` – A PowerPoint presentation slide summarizing the key insights
- `EL_DA_08.pdf` – Screenshot/Export of the Power BI Dashboard

## Key Insights

1. **Technology** is the top-performing category, contributing **70.71%** of total sales.
2. The **South region** recorded the highest sales among all regions.
3. **April** saw a peak in monthly sales, indicating seasonal demand changes.
4. The **average sale value** is ₹635, while the **maximum single sale** recorded is ₹2,000.

## Tools Used

- **Power BI Desktop** – For dashboard creation and data visualization
- **Microsoft PowerPoint** – To present summarized insights

  # Interview Questions

1. What does a dashboard do?  
A dashboard visually displays key metrics and insights from data, helping users make informed decisions quickly.

2. How do you choose the right chart?  
It depends on the data and the message—use bar charts for comparison, line charts for trends, and pie charts for proportions.

3. What is a slicer/filter?  
A slicer or filter allows users to dynamically narrow down data shown on visuals based on specific fields like region or date.

4. Why do we use KPIs?  
KPIs (Key Performance Indicators) track critical metrics like sales, profit, or customer growth to measure performance at a glance.

5. What did your dashboard show about sales?  
It showed Technology as the top category, the South as the highest-performing region, and a peak in April sales.

6. How do you make a dashboard look clean?  
Use consistent colors, align visuals properly, keep text minimal, and avoid clutter to ensure clarity and focus.

7. Did you clean the data before starting?  
Yes, cleaning ensures accuracy—duplicates were removed, and data types/formats were verified before loading into Power BI.
